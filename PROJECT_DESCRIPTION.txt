SkyCast - Weather Forecast Web App

A responsive weather dashboard built with HTML, CSS, and vanilla
JavaScript. It uses the Open-Meteo API to display current weather,
feels-like temperature, humidity, wind speed, precipitation, and a
five-day forecast. Includes city search, Celsius/Fahrenheit switching,
responsive design, and loading/error states.

Tech stack: HTML5, CSS3, JavaScript, Open-Meteo API.
